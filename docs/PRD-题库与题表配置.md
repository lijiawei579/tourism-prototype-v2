# V2 题库与题表配置 PRD

版本：V2.14。更新日期：2026-11-09。按最小配置路径替代旧的自动规则配置和配置总结弹窗。后端待集成范围不变。

## 1. 最短配置路径

新建题表→填写名称、类型、问卷总分（仅打分表）及节点→保存→建组→新建或选入题目→发布。保存和选题后回到当前题表，不弹配置总结；发布仅二次确认生效范围。

题库保留360题（7＋8＋345）和原文依据，细则一、二、三作为来源分类。题表管理分组、题目、节点和独立版本；专家自主判断或填分，省厅人工审批。

## 2. 新建与题库详情

新建弹窗不展示统计。名称必填且不得重复，默认打分表。打分表显示“问卷总分”，必填有限正数并支持小数；达标表隐藏总分且不校验。切换保留已输入总分。节点可多选或暂不挂载。

原“类型与节点”及表内同类入口统一改为“题库详情”。配置后详情可编辑名称、类型、总分及节点，保留四项只读统计：已配置题目、达标题、打分题、题目满分合计。复制沿用原配置，但打开新建界面，不显示统计。

问卷总分由管理员填写，与题目满分合计分别保存。增删改题目和同步修订只更新统计，不覆盖问卷总分。两者不一致仅供人工核对，不强制反复配平、不折算、不自动改题分，也不生成及格判定。

## 3. 最小题目配置

题型仅保留达标判断、人工评分。必填题干与来源分类（默认自定义）；人工评分另填有限正数满分。评分建议选填。新建、编辑及复制题目弹窗均不显示评分说明、配置提示与原文依据区域；不再要求填写说明。已有说明与原文依据仍保留在数据中，保存不会清空。新题默认人工评分，无强制建议档次；达标题隐藏分值与建议。

人工评分可展开选填建议，增删描述、最低分、最高分。已填建议要求文字完整且0≤最低分≤最高分≤本题满分；可重叠或未覆盖全部分数。固定档次上下限相同，建议不约束实际给分。

删除题级归零、限分规则及分值、豁免、数量加扣、方向、单位分和步长配置。分组只设名称、父组、选填说明，不配置组级归零或豁免。原规则仍作为只读依据或说明参考，系统不执行自动改分。

左侧管理分组及排序，右侧操作题目。跨来源选题、跨页勾选、修订、启停、复制、主动同步以及移除引用不删除原题的机制不变。

## 4. 专家作答

达标题由专家选择达标／不达标。所有打分题直接填写0至本题满分内的非负数字，支持小数，不因旧选项、数量、归零、限分、豁免或组条件改变实际分数。

输入就地保存、汇总和高亮匹配建议，不重绘整页。合法分数不命中建议也可提交。空白不同于0，空值、非法字符、负数和越界阻止提交；扣分依据、意见、附件及签字沿用原校验。

线上按专家原始分汇总，不折算。线下登记0至问卷总分内的实际汇总分。达标表不生成数值成绩。系统不替代省厅作审批结论。

## 5. 数据与兼容

题表新增questionnaireTotal（独立问卷总分）与humanScoringVersion；运行total引用该总分或0，题目合计由qbSum/qbStatistics独立计算。旧配置沿用原有总分，不随题目反复覆盖。

题库当前题型为qualification/manual，新增humanScoringVersion；advisoryBands保存可选建议。旧特殊规则在原文快照或说明中保留。升级追加发布版本与题库修订，重复加载不重复升级。

旧发布快照、在办绑定及已提交分数、答案、附件、签字不覆盖。旧版未提交题目呈现人工输入，实际填分后用directNumeric记录；历史只读。草稿可为空，发布要求非空题目、合法题分及分组；打分表需问卷总分及至少一道人工评分题。

## 6. 验收

1. 新建无统计；打分总分空、0、负数时定位总分；达标表无需总分。
2. 保存、选题、发布无配置总结弹窗；配置后“题库详情”保留统计。
3. 问卷总分100时，增删改题、同步后仍为100；详情准确展示题目合计。
4. 新建题目仅两种类型，无归零、限分、豁免、数量算法和步长；无建议也能保存发布。
5. 旧特殊条件不能改写新人工分；合法小数和档次外合法分可填，空白与越界不可提交。
6. 建题、选题、发布、新节点线上/线下评分、签字提交可完成；历史原分和V1不变。

# V2 题库与题表配置 PRD

版本：V2.13。更新日期：2026-11-06。系统管理员维护题库及题表；业务节点仍由原责任角色办理。此版覆盖旧的手填题表总分、及格线、折算及全部达标开关设计。

## 1. 产品关系

题库保存可复用题目：题干、说明、来源、题型、分值、选项或建议、特殊规则和修订。细则一、二、三是来源分类；初始360题（7＋8＋345），具体题型由题目配置，不由外层题表强制指定。

题表组织评分组和题目，并绑定流程节点。外层仅配置名称、达标表／打分表类型和绑定节点。管理员无须先决定题表满分；进入表内逐题配置后即可查看自动统计。

## 2. 新建、编辑与复制

入口：题表列表“新建题表”、卡片“类型与节点”、表内“题表类型与节点”。弹窗顺序：名称→两种类型→只读统计→节点多选→保存。默认打分表，复制时沿用原类型及节点，可继续修改。

达标表：仅记录逐题核验情况，不汇总数值成绩。打分表：汇总数值题实际得分，达标判断单独记录。切换类型不删除题目、不转换题型，不改变题库原始题分。

删除“本表需要打分”复选框、题表总分输入、通过门槛输入、计算方式选择、达标题必须全部达标复选框。无替代的隐藏配置，也不按标准及格线自动得出流程结论。

名称必填、不得重复。允许先保存空草稿，再进入表内建组和选题；发布时要求至少有题目，打分表至少有一道有分值的数值题。取消不保存。

## 3. 自动统计

只读展示：已配置题目数、达标题数、打分题数、题目满分合计。达标题指题型为达标判断的题目，其余为打分题；满分合计为全部打分题max之和，达标题不占数值分。

新增、选入、移除题目、修改题分和同步题库修订后，重新计算当前草稿统计，组分同步更新；不要求人工核对外部目标总分。卡片、表内概览、设置弹窗和配置总结使用同一统计逻辑。空表为0题／0分；可正常保存。达标表保留题分统计供配置核对，办理页面不生成数值成绩。

打分表实际分数为题目有效分的直接合计，不做等比例折算；题目自身的累加、封顶、归零、限分和豁免继续生效。

## 4. 题目维护

题库按来源、题型及关键词筛选，20题分页，支持新增、编辑、复制、停用、启用。五类题型为达标判断、条件判断（计分）、多选、数量计分、人工评分；具体交互见《数字评分与题型精简PRD》。数量加扣分通过方向配置；人工分直接数字填写、建议档次高亮。

题表内左侧管理组，右侧管理题。跨来源、跨页选题，已选题不重复加入；移除不删题库。修改题目产生题库修订，当前编辑表的草稿可同步，其他题表须主动同步；保留题表内编号和组结构。停用不删除已引用快照。

## 5. 结果、总结与发布

线上逐项保存答案和依据。达标表展示达标／不达标／待核验数量；打分表展示当前得分和题目满分合计。无及格线提示，不因分值低而生成“未通过”。达标与不达标是客观核验记录，不能替代省厅审批决定；提交校验仅检查答案、数字、依据、意见、附件及签字完整性。

线下上传打分表及对应阶段附件；打分表登记0至题目满分合计内的实际分，混合题表另登记达标项核验记录。达标表不要求虚构汇总分。

配置总结包含表类型、组数、题数、题型构成、满分合计、来源、节点与角色、版本、生效范围和校验结果，支持查看、复制和导出。保存、选题后可看总结，发布前核对总结。

草稿独立，发布生成版本。首次升级为当前发布配置追加statisticsOnly版本，移除threshold、calculation、requireAllQualified；scoreEnabled表示类型，打分表total为自动合计，达标表运行total为0。题库题分及源文档基线不改；旧版本字段只留在旧快照。已有在办绑定和已提交原始答案、分数、附件、签字不重算。重复加载不重复升级。

## 6. 验收标准

1. 新建／编辑只出现名称、达标／打分、统计及节点；找不到手填总分、及格分、折算和全部达标控件。
2. 空表可保存但不能发布；15分题选入后统计15，改20后统计20，移除后归0。
3. 题表内编辑只更新草稿，发布版和历史绑定仍保留原分；同步后保留题表内编号及分组。
4. 达标表不强制改变表内题型，显示客观核验记录；打分表得低分仍可在材料完整后提交，不自动判定流程通过或不通过。
5. 卡片、概览、设置及导出总结统计一致，无无效数值、缺失字段或旧及格线提示。
6. 现有节点权限、线上／线下方式、签字、证据及公示归档规则不变，V1不改。

真实服务端CRUD、审计、发布接口及权限集成保持原待集成范围，本次仅修改前端演示与PRD。

# V2 题库与题表配置 PRD

更新日期：2026-11-04。角色：系统管理员配置题库/题表，原责任角色办理节点。按用户本次要求，覆盖上一版“正式表总分和题型不可修改”的限制。V1不变；不新增业务审批节点，不更改专家原始记录。

## 1. 产品关系

题库是可复用题目集合，包含来源分类、题干、说明、题型、选项、题目满分/选项分、特殊计分规则及依据。“细则一/二/三”只是题库来源分类，不强制绑定固定流程，也不锁定题目内容或分值。现有360题（7+8+345）作为初始内容，保留正式原文供对照。

题表在题库之外配置：名称、选题、组结构/顺序、是否计分、计算方式、总分、通过门槛、达标判断要求、一个或多个绑定节点。题表可以同时包含达标判断和数值题；达标题不占数值总分。

## 2. 页面与功能

题库与题表菜单分为“题表配置”和“题库管理”。题库按来源分类/题型/关键字筛选，分页，支持新增、编辑、复制、停用；已引用或历史记录不因停用消失，停用后不能新选入。题目编辑支持全部现有题型；内容和分值可改，原文留存。保存题目产生新修订，不立即更新已发布题表。

题表列表展示计分开关、总分/门槛、题数、绑定节点、版本、草稿状态。新建/编辑在外层表配置弹窗进行；也可复制题表。内层仅管理组、题目、选题和排序，不配置整表总分。组操作保持左侧，右侧仅题目操作。

题表选题弹窗支持题库来源分类、关键字检索、跨页勾选、当前页全选和已选计数；确认选入当前组，重复引用同一题目时不重复添加。可移除题目、编辑题库题、主动同步最新题库修订；同步仅写当前表草稿，不改发布版。评分组可嵌套，组/题规则与计算一致。

## 3. 整表计分

- 不计分：题表只收集答案，隐藏分值，不产生虚构数值成绩；可配置是否要求达标题全部达标，或仅由办理人形成结论。数值题仍按原题的选项/数量/文本方式填写，但不计分。
- 计分：达标题单独判断，数值题计算原始题分。按原分累加时，配置总分须等于数值题满分之和；不相等时明确提示选择折算或调整题分。
- 折算：最终分 = 原始得分 / 数值题满分合计 × 题表配置总分，保留两位小数；通过门槛使用折算后的题表分制。不能用达标题为0的题表除零。
- 达标题可与数值题混排；“全部达标”开关启用时，达标失败不能被数值高分抵消。可以带依据提交未通过，不强制补完剩余数值题。关闭该开关时，只收集核验情况，由节点办理人综合判定。
- 题目内部算法继续支持单选、多选累加、数量加扣分、区间、人工、完整性、归零、封顶和豁免。修改与正式原文不同时展示“配置已调整”，不宣称修改后的配置仍是正式标准原值。

## 4. 配置总结

每张题表提供“配置总结”：表名、计分开关/公式、原始题分合计、配置总分/门槛、达标条件要求、题型统计、组数/题数、来源分类、挂载节点与操作角色、版本/生效范围、配置校验结果。可复制文本和导出总结。保存/选题后可查看草稿总结；发布确认前也先展示总结，不能越过校验。

## 5. 节点行为与历史

延续原版本规则：未挂题表使用默认双栏（左材料，右办理内容和流程记录）；挂题表的当前办理角色使用题表页面，审批动作仍由原角色完成，不由计算分数自动流转。专家在评分环节先选择线上/线下；线上显示绑定版本的题表，线下在默认双栏上传材料与登记表级结果；不计分题表不要求录入汇总分。评分后签字。

题库修订、题表草稿和发布版本隔离。已开始节点绑定已发布的题表快照；历史原始分、答案和附件不重算。题库停用/改题、修改总分、换节点挂载均只影响后续发布与未开始节点。初始题表仍按当前4A业务配置：前提条件不计分且全部达标、资源价值100分/80、设施服务1000分/850，管理员可按需求调整后发布。

## 7. P0验收

1. 原始题目可检索并编辑内容/分值，题库内没有整表计分开关/总分/流程挂载。
2. 外层题表可开启/关闭计分，配置总分、门槛、算法和多节点挂载；内层可从不同细则选题。
3. 编辑/停用题库题不改变已发布表；主动同步当前表草稿后可校验再发布。
4. 原分累加不一致拦截；折算后实际答案变化使题表总分正确变化；达标题不参与数值累计。
5. 不计分题表可完成填写提交；线上/线下与历史记录均不显示伪造总分。
6. 配置总结可查看、复制/导出，并说明草稿、计分公式与生效范围。

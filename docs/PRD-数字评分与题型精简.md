# 数字评分与题型精简 PRD

版本：V2.12。更新日期：2026-11-06。本节覆盖旧文档中的“先选择分档再给分”交互规则，标准原文、满分、题表合计与流程权限不变。

## 1. 专家直接填写分数

分档单选、分档区间、人工酌情给分、完整性组合统一为人工评分题：上方展示建议描述和分值区间，下方直接填写数字。建议行不提供单选按钮，也不能点击改分。输入事件立即保存草稿、更新总分和对应档次高亮，不重建页面或丢失焦点。蓝色底及“当前匹配”文字共同表示匹配，不能只靠颜色传达。

仅接受非负数字；支持配置步长所允许的小数。禁止字母、正负号和科学计数法输入、非法粘贴；同时校验空值、有限数值、上下限和步长。空白不同于0，清空后取消高亮并作为未完成评分处理。超出本题满分不高亮且不能提交。固定档次之间的分数不强制改为某档，允许专家在合法范围内填写并结合原文解释；档次为建议，不是审批结论。扣分依据仍按原校验要求填写。

原完整性组合的建议用总分表达：空间完整5分加实体1至5分，对应6、7、8、9、10分；空间不完整对应0分，保留原文归零条件及核验说明。无论任何题型，条件归零、限分和豁免仍作用于有效得分；记录保留原始填写分及条件，不能借建议高亮绕过归零。

仅有笼统酌情要求、没有明确多档分值的条目，展示原文和原有满分参考及0分，不虚构“优秀、良好、一般”的档次。

## 2. 创建题目的五类交互

| 类型 | 配置内容 | 专家作答 |
| --- | --- | --- |
| 达标判断 | 题干、核验说明；不显示本题满分和数量配置 | 达标／不达标，不占数值总分 |
| 条件判断（计分） | 满分、符合条件文字及对应得分；系统保留末尾0分 | 满足条件或不满足 |
| 多选题 | 选项文字与分值、题目满分；保留互斥组规则 | 多选累计封顶，0分与其他项互斥 |
| 数量计分题 | 加／扣方向、单位分、数量名称、满分 | 填写非负整数数量，按方向计算 |
| 人工评分题 | 满分、步长、建议档次文字／最低分／最高分、特殊条件 | 直接填数字，自动高亮建议 |

新建、编辑、复制统一使用相同类型表单。切换题型只展示对应字段，保留当前题干与说明。人工评分支持添加／删除建议；最低分等于最高分表示固定分档。建议文字不能为空、数值须有限、0≤最低分≤最高分≤题目满分，区间不能重叠；不满足时停留弹窗并定位错误，不保存。数量加分从0起、以满分封顶；数量扣分从满分起、最低0分。V2.13起，题表外层仅配置达标／打分类型及节点，满分由题目自动统计，不再配置总分、及格线或折算。

## 4. 数据与版本

人工评分题新增advisoryBands（key、label、min、max）、numericEntryVersion、legacyMode；完整性项保留integrityReference和zeroRule。数量题沿用unit和countLabel。答案沿用score/rawScore，新增directNumeric用于记录直接填写方式；原始选项键不冒充新的专家选择。

原始来源目录scoring-catalog.js留存作为标准基线，新交互由numeric-scoring.js投影。首次升级为题库追加修订，题表追加发布版本，后续绑定使用新版本；已存在的版本快照不覆盖。已经开始的表保留绑定与原始分，作答控件可呈现直接填分建议，只有专家实际输入才更新当前草稿；已提交历史保持只读。重复加载不得重复追加版本或修订。不覆盖管理员已改过的分值与题干。

本期前端演示，不新增后端服务。现有省厅人工审批、签字、上传、OCR和创建期状态规则不变。

## 5. 验收

1. 专家填7、5、0时，对应固定档次立即高亮；输入12时资源价值12至13分档高亮。
2. 清空、越界、非法输入、步长不符均不能完成评分；0可明确作为已填值。
3. 当前页面与输入焦点保持，输入不触发整页重建；切换评分组后草稿及高亮恢复。
4. 新建弹窗仅有五类；切换类型对应字段随之改变，数量方向可切换加分／扣分。
5. 编辑建议区间错误不得保存，修正后能保存、选入题表、预览、发布并在新节点使用。
6. 原有题目总数、满分及归零／豁免不变，已提交历史原始分与签字不变，数据迁移幂等。

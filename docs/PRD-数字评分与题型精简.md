# 数字评分与题型精简 PRD

版本：V2.14。更新日期：2026-11-09。本节与《题库与题表配置PRD》共同替代旧五类题型及特殊条件自动计分设计。

## 1. 两种题型

达标判断由专家选择达标／不达标，不计分。人工评分由专家直接填写0至本题满分内的非负数字，支持小数。

原分档、区间、条件、多选、数量加扣和完整性算法均改为人工评分参考。保留360题、题干、满分和原文快照，不通过条件或数量自动改分。已提交历史仍保留原始记录。

## 2. 最小配置

题干与默认来源分类必填，人工评分另填本题满分。评分建议选填；题目弹窗删除评分说明、配置提示与原文依据区域，已有数据保留且不会因保存被清空；新题默认人工评分，无强制建议档次。无归零、限分、豁免、数量方向、单位分和步长配置；分组仅组织题目。

已有分档作为参考建议，可增删描述、最低分及最高分。已填建议需文字完整且分数范围合法；可重叠或不覆盖全部分数，不限制专家给分。0分建议显示在最后。

## 3. 作答交互

填数即时保存草稿、更新汇总、实时高亮命中建议，不重绘整页。合法分数未命中建议也可提交。空白和0区分，非法数字、负数、非有限数值和越界不可提交。扣分依据、意见、附件和签字按原业务要求。

不因旧的归零、限分、豁免、数量或组级条件自动改写人工分。系统仅客观展示，厅方人工审批。问卷总分独立配置，题目合计仅作统计，不自动覆盖。

## 4. 数据与兼容

人工题使用mode=manual、advisoryBands及humanScoringVersion；答案保留score/rawScore和directNumeric。旧自动规则转为参考说明或原文快照，新配置不执行。题表追加发布版本、题库追加修订，旧快照不重写，重复加载幂等。

停车等候、充电桩、管线隐蔽的明确档次保留为建议；工具用品等计数条目按原文人工核验，不自动按数量加分。历史分、签字、节点权限和后端待集成范围不变。

## 5. 验收

两类题均可按最少必填字段保存选入；无建议可评分，有建议填数即时高亮；特殊条件不影响新人工分；合法小数与档外合法分可填，清空和越界不可提交；刷新保留草稿，历史不重算。

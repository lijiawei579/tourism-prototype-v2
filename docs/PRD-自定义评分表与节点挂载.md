# V2 自定义评分表、节点挂载与专家评分方式 PRD

> 历史参考：当前行为以[题库与题表配置PRD](PRD-题库与题表配置.md)及[完整PRD](PRD.html)为准。本文“正式表总分/门槛不可修改”等限制已被取消；题目归题库管理，整表计分及节点绑定归题表外层配置。

版本：2026-11-03。范围：V2 前端交互原型。本文件取代旧说明中“固定三张表、固定挂载节点、按阶段共同发布”的限制。正式细则作为预置表保留，历史已提交评分不变；不增加业务流程节点，不接入真实后端、OCR或地图服务。

## 1. 目标、角色与优先级

P0：管理员按“评分表 → 评分组 → 评分项”配置，专家按节点选线上或线下评分，其他操作人保留原有审批职责。配置不能改变专家历史原始分数，不能自动代替厅方作出审批结论。

验收目标：组操作全部位于组区域；新建自定义表可发布挂载并真实显示；未挂载节点为默认双栏；专家两种方式均可保存、校验、签字和提交。

## 2. 自定义评分表

列表显示表名称、计分性质、组数、项数、发布版本、挂载节点和草稿状态；可新建空白数值表/达标表或复制正式表。空白表无预设业务判断，不冒充正式细则。

表信息可编辑名称、多选挂载节点。支持不挂载、一个节点多表、一表多节点。可挂载厅方初审、专家资料审核、线下专家会议评审、省文旅厅复审、现场创建期、现场评审、上会审定、评定结果公示；申报填报与办结归档不改成评分页面。新表还可配置数值满分、通过门槛或全部达标。正式表总分与门槛保留文档约束。

表、组、项修改只形成该表草稿；校验后发布生成不可变版本快照。可放弃本表草稿、预览试算、导出、查看发布记录。草稿挂载不生效；发布后的挂载仅用于尚未开始办理的节点，已开始节点绑定原版本（包括当时未挂载的空绑定），不追溯更改在办表单或历史。

## 3. 组与项操作归属

左侧“评分组”区域：新增组、当前组名称、编辑、删除空组、上移、下移、组树选择。父子关系不能成环，非空组不可直接删除。右侧只保留新增评分项、项编辑/删除、项预览及列表分页。原文依据、组级归零和豁免仍展示。

题型继续使用共用规则引擎：达标判断、分档单选、区间、条件、多选累加、数量加扣分、人工给分、完整性组合；保持0分末尾、封顶、归零、豁免、条件限分与组分约束。未填写不等于0分；扣分须写依据。

前提条件不达标时须写核验依据，可以直接提交未通过意见，不强制补齐后续数值评分。未继续评分的条目保持未填，不生成逐项分数。

## 4. 页面解析规则

默认流程页：左侧是申报方提交的原始填报内容与附件，只读；右侧是当前责任人的原有判断、上传/提交操作与本次流程记录。不显示未来节点操作。

挂载了已发布评分表的节点：当前有权操作的角色进入评分表页，按表切换、按组选择，评分表下仍保留原有节点审批/提交内容。分数或达标结果仅辅助办理，不自动推进流程。无权操作角色仍为只读材料与当前流程状态，不开放评分控件。

节点开始时记录当时的表版本及空挂载快照；后续配置修改不改写已开始节点。结束节点只读；默认不将配置变动应用于已结束项目。

## 5. 专家评分方式

线下专家会议评审、现场评审：受派专家完成项目级回避确认后，先选择“线上评分”或“线下评分”。没有挂载评分表时线上选项置灰并说明，线下仍可办理。线上/线下是录分方式，不改变业务节点名称或组织方式。

线上：完整评分表页面，可切表、切组，查看材料弹窗，上传评分表/OCR或现场附件，填写逐项得分、扣分依据、整改要求和阶段综合意见。沿用正式文档来源，按绑定版本校验。可提交不达标/不通过意见，不强制给通过分。

线下：默认双栏，左侧只读申报材料；右侧上传打分表，填写各数值表汇总得分或达标表结论及综合意见。现场评审还需提交现场照片和现场验收报告，照片可填写简述（非必填）；关联单项问题可填写问题、整改与照片。未挂载任何表时填写评审通过/不通过结论。上传/OCR为演示能力，不能宣称已识别真实附件。

未提交前可返回更换方式，弹窗确认；两种草稿分别保留，只校验当前方式。选择线下不伪造逐项线上答案，汇总不能冒充逐项原始评分。所有必填有演示初始值，附件提供显式“模拟上传”。专家完成当前方式内容后签字，回避确认不签字，提交后返回项目列表。

## 6. 记录与权限

已提交评分方式、绑定版本、表结果、逐项答案（线上）、线下附件与汇总分、专家意见、签字和提交时间只读归档。厅方与有项目查看权限的专家可查看，申报方看不到内部原始评分。历史旧版评分继续使用旧版记录，不重算、不补造线上答案。厅方不能编辑专家原始分数。

## 7. 数据与接口边界

新增 scoringLibrary：每表 published、draft、versions；表含 nodeKeys、kind、total、threshold、groups、items。新增项目 nodeScoreBindings：按节点固定 tableId/version 引用。新增专家评分草稿 scoringMethod、mountScore（按表存答案/组条件）、offlineResults（线下表结果），节点非专家评分放 nodeScoreDrafts。专家 sheets 原字段及历史保留。重复项ID以表ID隔离。

未来接口建议：评分表CRUD/发布/版本查询、节点挂载查询、项目节点绑定、节点评分草稿与提交、专家附件与签字接口。本轮仅本地持久化，不改真实接口。

## 8. 验收用例

1. 管理员选中组后，编辑/排序位于左侧；右侧没有组编辑按钮。
2. 新建空白表、添加组/项、挂载节点；保存草稿不生效，校验发布后尚未开始节点可用。
3. 取消表挂载并发布，后续节点显示默认双栏；已开始/已提交节点仍引用原版本。
4. 专家首次进入出现方式选择；线上看到完整表，线下看到材料与上传提交区。
5. 切换方式保留草稿，附件缺失或分数越界阻止提交并定位；完成后签字提交返回列表。
6. 厅方可查看专家两种方式的只读明细，申报方无内部得分入口。
7. 线上选择/录分不整页刷新，切表/切组才更新页面；V1文件不变。

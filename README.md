使用 GitHub Pages 从 main 分支根目录直接发布。所有运行依赖均在本仓库，无需安装依赖或构建。

包含省厅审核人员、市州申创人员、评审专家、系统管理员的前端业务演示。OCR为模拟识别；AI检索及智能助手本期不开发。没有真实登录、后台数据库、文件服务或跨设备签字服务。

当前演示聚焦4A级景区申创。管理员在“题库与题表”中管理360道初始题目、题库修订、跨来源选题、题表分组、整表计分/折算/总分/门槛、多节点绑定和配置总结。发布只影响尚未开始的节点；专家历史原始分不变。讲解与完整PRD使用同一份交互目录。

本版补齐独立的“省厅资料审核意见汇总”节点，补证后仍返回该节点。系统只客观展示评分与核验结果，不替代省厅人工审批。公示异议关联具体景区；公示期满有无异议均归档，保留异议记录，由省厅人工确认申创成功或未通过，两种结论均保持归档。流程图的判断菱形无编号。

仅含内置演示数据，不包含本地浏览器中手工上传的文件、填报记录、签字、账号凭据、旧版原型或原始业务文档。各访问者的数据仅保存在本人的浏览器中，不会共享。公开仓库中的源码、内置演示数据与PRD可被查看。

手写签字演示仅支持同源、同浏览器页面回传。线上地址与本地地址的演示数据相互独立。请勿将真实业务资料上传到演示系统。

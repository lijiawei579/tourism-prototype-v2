# 旅游品牌申创管理系统 V3.0

- [线上演示](https://lijiawei579.github.io/tourism-prototype-v2/v3/)
- [原型讲解](https://lijiawei579.github.io/tourism-prototype-v2/v3/?explain=1)

本地演示可解压后双击 `index.html`。页面内可切换省厅审核人员、市州申创人员、评审专家和系统管理员。点击「原型讲解」可阅读交互说明和随附 PRD。PRD 保留已有章节和版本记录。

原型使用浏览器本地数据及模拟附件，仅用于演示。若浏览器限制本地文件存储，请使用线上入口，或用静态 HTTP 服务打开此目录。演示签字回传依赖同源浏览器页面。
